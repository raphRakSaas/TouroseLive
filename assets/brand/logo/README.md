# TouRose logo system (2C — Ville rose pin)

Trois déclinaisons à utiliser selon le contexte.

| Fichier | Usage |
| --- | --- |
| `tourose-logo-full.png` | Header, splash, docs — pin + wordmark |
| `tourose-logo-mark.png` | Favicon, app icon, avatar, cas où l’espace est trop petit |
| `tourose-logo-wordmark.png` | Quand le pin est déjà affiché à côté (footer, co-branding) |

## Couleurs

- Rose briques / accent : `#E8527A`
- Anthracite : `#222222`
- Fond : blanc

## Règles

- Ne pas déformer le pin
- Ne pas recolorer hors palette
- Espacement clair autour du mark (zone de protection ≈ hauteur du pin)
- Sur fond sombre : préférer une version inversée (à produire plus tard)
