Confidentialité & utilisation

TouRose est un compagnon open data en lecture seule.

Confidentialité

Aucun compte utilisateur n’est requis pour l’instant. Aucune donnée personnelle n’est collectée volontairement. Les appels API partent de ton navigateur / serveur local vers des sources publiques (OpenAgenda, Toulouse Métropole, Open-Meteo, etc.).

Les photos de lieux peuvent provenir de Wikimedia / Wikidata ; les crédits restent attachés à ces plateformes.

Conditions d’utilisation

TouRose agrège des données ouvertes « en l’état ». Les disponibilités Vélô, alertes Tisséo, occupation parking ou horaires d’événements peuvent être incomplètes ou retardées.

L’outil est fourni sans garantie. Pour une décision critique (trajet, accessibilité), vérifie toujours la source officielle.

Paramètres

Pas encore de préférences persistantes. Prochaines pistes : quartier favori, couches carte, thème clair uniquement (on reste volontairement light).
